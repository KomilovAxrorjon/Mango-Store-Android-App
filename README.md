# Mango Store – Android App
Mango Store is a mobile application developed for Android as part of the Mobile Application Development coursework. It simulates key features of a basic e-commerce marketplace from the admin perspective, allowing product management through a simple and intuitive interface.

## Project Summary
- Course: Mobile Application Development
- Assignment Goal: Build a basic admin panel for a marketplace using a given backend API
- Platform: Android (Java/Kotlin with XML UI)
- Grade Received: 74 / 100
- API: Provided by the module (no backend development required)

## Features
- Product Listing – Display all added products on the homepage
- Add Product – Create and upload new product entries
- Update & Delete – Full CRUD support for managing product data
- Product Details View – View full details for each product
- Drafts – Save and view draft products (not yet published)

  ## Tech Stack
- Language: Java / Kotlin
- UI: XML-based Android Layouts
- Backend: REST API (provided by instructor)
- Tools: Android Studio, Git, GitHub

## Setup & Installation

1. Clone the repository:

```bash 
git clone https://github.com/KomilovAkhrorjon/Mango-Store-Android-App.git
```

2. Open in Android Studio
3. Build and run on emulator or physical device
